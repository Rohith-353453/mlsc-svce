# Contributing to DevDash

Thanks for participating! Here is how to contribute:

1. **Pick an Issue:** Find an open issue that interests you. Comment on it to let others know you're working on it.
2. **Fork and Clone:** Fork this repository and clone it to your local machine.
3. **Build:** Create your solution. You can put your code in a new directory or just share a link to your project in the PR description.
4. **Submit a PR:** Create a pull request to the main branch. Fill out the pull request template.
